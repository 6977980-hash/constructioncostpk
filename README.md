# ConstructionCostPK Fixes

WordPress plugin with site-specific fixes for https://constructioncostpk.com/.

The repository root **is** the plugin folder. Hostinger Git deploys this repo into:

```
public_html/wp-content/plugins/constructioncostpk-fixes
```

Then activate **ConstructionCostPK Fixes** in WP Admin → Plugins. New fixes go in `includes/` (one file per fix) and deploy on push to `main`.
